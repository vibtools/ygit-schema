# Documentation Assets

Documentation images, diagrams, and screenshots belong in this directory.

Requirements:

- Use descriptive lowercase kebab-case filenames.
- Provide alternative text in all documentation usage.
- Optimize raster images before committing.
- Do not embed private metadata, credentials, or personal information.
- Prefer SVG for diagrams and interface illustrations when appropriate.

Source brand assets remain under `assets/`; deployable assets are copied to `public/`.
