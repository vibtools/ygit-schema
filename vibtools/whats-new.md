# What's New in VibTools

Stay up to date with the latest improvements, visual updates, and user-friendly features in VibTools.

---

## 🌟 Version 1.0.0 Highlights

### 🎨 Social Media Preview (OG Image) Support

We have introduced native Open Graph (`ogImageUrl` and `ogImage`) support in the VibTools schema.

- High-definition `1200x630` social cards now render automatically when your tool link is shared.
- Included pre-built, elegant branding graphics in `vibtools/assets/og-image.png`.

### 📖 Dedicated Guides for Non-Technical Users

We added a complete suite of documents written in plain, friendly language:

- **Quick Start Guide (`quick-start.md`)**: Get started in 3 simple steps without coding.
- **Features Guide (`features.md`)**: Visual walkthrough of presets, automation, and privacy.
- **FAQ (`faq.md`)**: Answers to everyday questions about privacy, usage, and updates.
- **What's New (`whats-new.md`)**: Easy-to-read summary of latest enhancements.

### 📁 Unified `vibtools/` Folder

All assets, user documentation, and manifest definitions are now organized in a dedicated `vibtools/` project directory for seamless browsing and maintenance.

### ⚡ 1-Click Catalog Import

Connecting a tool or repository to catalog sites is now instantaneous. Simply enter the repository name and all product details populate automatically.
