Getting Started with VPMS

Learn how to create, validate and maintain vibproject.ygit manifests using the official YGit schema registry.

Quick Note
Always reference the official schema URL inside your manifest before validation.

Step 1 — Create a Manifest

Create a file named vibproject.ygit in the root of your project.

{
  "$schema":"https://schema.ygit.dev/v1/vibproject.schema.json",
  "schemaVersion":"1.0",
  "manifestVersion":"1.0"
}

Step 2 — Validate

Use your preferred validator or future YGit CLI to validate the manifest against the published schema.
