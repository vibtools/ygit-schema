# Frozen Roadmap Rules

পরিবর্তন করা যাবে না—

- Development Order
- Phase Sequence
- Foundation → Layout → Components → Pages → Content → Search → Optimization → QA → Release
- Official Technology Stack
- GitHub → Cloudflare Pages Deployment Pipeline
- Design System Compliance
- Coding Standards Compliance
- Component Development Rules Compliance

নতুন Feature যোগ করা যাবে, কিন্তু Phase Order পরিবর্তন করা যাবে না।
