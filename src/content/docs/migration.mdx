# Migration

VPMS Version 1 is the first published schema generation, so no earlier migration is required.

When a future major version is introduced, this section will document:

- Added, removed, and renamed properties.
- Required manifest transformations.
- Compatibility implications.
- Before-and-after examples.
- Validator and tool upgrade requirements.

Version 1 manifests remain valid against the Version 1 schema and are not automatically rewritten.
