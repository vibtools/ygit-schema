# Support

## Usage questions

Use GitHub Discussions for installation, schema authoring, validator usage, registry integration, and migration questions. Search the documentation and existing discussions before creating a new topic.

## Defects

Use the structured bug-report form for reproducible defects in the schema, examples, validator, documentation, website, or automation. Include the project version, environment, command, expected result, and complete non-sensitive diagnostic output.

## Security reports

Follow [SECURITY.md](SECURITY.md). Security-sensitive information must not be posted publicly.

## Scope

Support covers the documented YGit Schema repository, VPMS Version 1, official examples, bundled Python tools, and the registry portal. Project-specific manifests, third-party tooling, hosting-provider accounts, and unrelated YGit ecosystem products are outside this repository's support scope.
